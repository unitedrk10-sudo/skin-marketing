# 병원 마케팅 사례 조사 (누적)

병원·마케팅 회사·유치업자가 **어떻게 홍보하는지**를 조사할 때마다 여기에 같은 틀로 쌓는다.
목적: 나중에 한꺼번에 비교해 **가져올 장점**을 뽑고, 사업 방향(매체·제작 대행·스폰서 트랙)을 정하는 데 쓴다.
우리 기준(시스템의 선·중립·출처)은 `docs/marketing-framework.md`, `docs/derm-content-automation.md` 12장.

## 지금까지 뽑은 "가져올 것" (누적)
- **반영됨**: 한 문장 포지셔닝("Korean skin treatments, explained honestly"), SNS `ask` 글, 아는 사람 말투 — 릴리브 (2026-10-19)
- **후보**: 병원 영문 사이트 수준의 구조화 데이터(의사·학회·FAQ) — 스폰서 병원 제안서에 "공식 사이트 점검 항목"으로 (애드플라이어)
- **후보(보류)**: 다국어(아랍어·번체 중국어) — 영어 글 10편 이상 + 유입 국가 데이터 뒤 (릴리브)

## 반복해서 보이는 패턴 (가져오지 않음, 우리 차별점)
- 소수 병원만 앞세우는 "추천·매칭" + 병원에서 돈 받는 구조 (애드플라이어 myseoulclinic) → 우리는 공공데이터 기준 전부·거리순, 추천 없음, 병원에서 알선 수수료 없음
- 광고 표시 없는 상단 배너 (medicaltravelkorea.com) → 우리는 광고 표시 항상 분명히
- WhatsApp 예약·할인 쿠폰 (릴리브) → 시스템의 선: 공식 사이트 도착까지만
- 병원이 연락해 진행한 인플루언서 체험 글·광고 표시가 안 보이는 협찬 영상, 유료 보도자료로 만든 "Top 3" 순위 (세니아) → 우리는 체험담·순위·추천 없음, 광고는 표시
- 저가 입문가(부가세 별도) → 현장 상담에서 추가 시술 권유 (세니아 후기) → 우리는 가격 단정 안 함, 상담 연결 안 함

## 1. 릴리브의원 (2026-10-19 조사)
- **유형:** 피부과 의원 (신논현·강남권, "통증 없는 피부과")
- **마케팅 주체:** 국내 SNS는 원장 본인. 해외용 영문 사이트는 애드플라이어 네트워크로 추정됨(2번 참고: 같은 테마·같은 CSS 클래스 이름 `g-navigation`, 같은 도메인 형식 `<병원>clinicseoul.com`). 확정은 아님.
- **채널·방식:**
  - 국내: 원장 개인 Threads(@nopain_relieve, 팔로워 약 4.5천). "통증 없는" 한 단어 포지셔닝, 원장 1인칭 소신 글, "좋은 피부과 조건" 같은 독자 참여형 고정 글(댓글 160개), 환자 글은 리포스트로만 보여 줌.
  - 해외: relieveclinicseoul.com (WordPress·GeneratePress, 영어·아랍어·번체 중국어). "Honest Guide", "Why Is Korean Botox So Cheap? An Honest Breakdown" 같은 솔직함을 내세운 SEO 글. WhatsApp 예약, 사이트 전용 ₩100,000 웰컴 기프트. ELLE 기사를 구조화 데이터(subjectOf)로 연결. 하단에 bestskincareinkorea.com 링크.
  - 외부: myseoulclinic.com 이 "직접 함께 일하는 4개 클리닉"으로 소개.
- **대상 고객:** 국내 + 외국인(영어권·중동·중화권)
- **돈 버는 방식:** 진료비
- **장점:** 한 단어로 기억되는 포지셔닝, "솔직하게 설명" 톤의 블로그, 독자에게 묻는 글로 참여를 끌어냄
- **가져온 것 (2026-10-19 반영):** ① 한 문장 포지셔닝을 SNS 말투 기준으로("explained honestly" — 아는 사람이 솔직하게, 출처 있는 분명한 입장, 영업 말투 금지) ② 독자에게 묻는 글(SNS 종류 `ask` — 여행·계획 질문만, 병원·후기·경험 질문 금지) → 답을 다음 주제로.
- **가져오지 않는 것:** 의사 1인칭 경험담·"우리 병원" 홍보·환자 후기 리포스트(의료인 본인 계정이라 가능한 방식이고, 우리가 하면 비의료인 광고·체험담), 할인 쿠폰, WhatsApp 예약 연결(시스템의 선 — 상담·예약 연결 안 함).
- **경쟁 구도:** "정직한 가이드" 포지셔닝은 병원·유치업자도 쓴다. 우리 차이는 ① 병원 소속이 아닌 중립 ② 문장마다 출처 링크 ③ 병원 추천·매칭을 하지 않음 — 이 셋을 About·SNS에서 분명히.
- **후보(보류):** 다국어 페이지.
- **출처:** threads.com/@nopain_relieve, relieveclinicseoul.com, myseoulclinic.com

## 2. 애드플라이어컴퍼니 (Adflyer Company) (2026-10-19 조사)
- **유형:** 병원 마케팅 대행사 + 보건복지부 등록 외국인환자 유치업자 (A-2024-01-01-5767). 주소: 서울 서초구 바우뫼로7길 8, 801호. 대표자·사업자번호는 사이트에 없음.
- **마케팅 주체:** 자체
- **채널·방식:**
  - 국내 대행(adflyercompany.com): 비급여 병원 컨설팅, 바비톡 같은 성형·미용 앱 입점·운영, 경쟁·고객 분석, 디자인, 계약 후 정기 방문 관리. "서울·경기 고객 약 200곳, 사례 100건 이상". 카카오톡 상담, 회사 소개서는 구글 문서.
  - 해외 유치(myseoulclinic.com): 영문 병원 매칭 사이트. "95개 병원 검증(강남·신사·압구정·홍대·명동)"을 내세우면서 실제로 연결하는 곳은 4곳(Aive, Relieve, Pladen, Cliff). 같은 페이지에 "3 English-Speaking Partner Clinics"도 있어 숫자가 맞지 않음. 메타 픽셀·GA·Site Kit.
  - 병원별 영문 공식 사이트: aiveclinicseoul.com·relieveclinicseoul.com·en.pladen.com 이 myseoulclinic 과 같은 CSS 클래스 이름(`g-navigation`)을 씀. myseoulclinic·Relieve·Aive·Cliff 는 같은 테마(GeneratePress). WhatsApp 연결, 의사·학회·FAQ 구조화 데이터. → 대행사가 영문 사이트를 만들어 주고 유치 사이트로 환자를 보내는 구조로 추정.
- **대상 고객:** 국내 비급여 병원(대행) / 외국인 환자(유치)
- **돈 버는 방식:** 대행료 + 유치 쪽은 "$0 Cost to You — We're Paid by Clinics" (환자 무료, 병원이 지불. 형태·금액은 미공개)
  - 정정: 이전 메모의 "소개 수수료 없음"은 틀림. 2026-10-19 현재 메인에 "병원이 돈을 낸다"고 적혀 있음.
- **장점:** ① 대행(사이트 제작) + 유치(환자 유입)를 한 회사가 묶어 병원 입장에서 원스톱 ② 병원 영문 사이트의 구조화 데이터 수준 ③ 지역별(5개 권역) 정리
- **가져올 것 (후보):** 스폰서 병원 제안서에 "영문 공식 사이트 점검 항목(의사·학회·FAQ 구조화, 언어 지원 표시)"을 넣기 — 우리 링크가 도착하는 곳의 품질이 곧 우리 성과.
- **가져오지 않는 것:** 소수 병원 추천·매칭과 병원에서 받는 유치 대가(§27 알선 — 우리는 유치업자 등록 전까지 안 함, 시스템의 선), 병원 사이트 제작과 중립 매체의 혼합(중립성 훼손).
- **우리와의 차이:** 우리는 공공데이터 기준 반경 내 병원 전부·거리순, 추천 없음, 병원에서 알선 대가 없음, 광고는 정액 + 표시. 이 대비를 About·영업 자료에서 분명히.
- **확인 안 된 것:**
  - bestskincareinkorea.com 은 "500개 이상 병원 비교·후기·무료 상담"을 내세움. 운영자 표시 없음, GA ID 도 다름(G-FYM8NV1GPH vs myseoulclinic G-70CGH3LK2X). 릴리브 하단 링크 하나뿐이라 관계 불명.
  - medicaltravelkorea.com 은 광고 표시 없는 병원 배너가 맨 위에 있음. 애드플라이어와의 연결 흔적 없음.
  - 이름이 비슷한 '애드플라이'(2017 설립, 2021 미니라이프 인수)와는 별개로 보임.
- **출처:** adflyercompany.com, myseoulclinic.com, aiveclinicseoul.com, relieveclinicseoul.com, en.pladen.com, cliffclinic.com, bestskincareinkorea.com, medicaltravelkorea.com


## 3. 세니아의원 / Xenia Clinic (2026-10-21 조사)

- **규모·운영 형태 (공개 정보):**
