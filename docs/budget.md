# 운영 예산 — 정보 제공 기간 (수익 전) 기준

> 작성 2026-09-28. 가격은 공개 요금표 기준 추정치이며 환율은 1달러 = 1,400원으로 가정. 실제 사용량은 운영 2~4주 후 다시 맞춘다.
> 전제: **수익 전 정보 제공 기간 12개월** (9~15개월 범위), 법률 자문은 수익 단계 진입 시점에 진행.

## 3. 시나리오별 월 예산
| 시나리오 | 구성 | 월 | 12개월 |
|---|---|---|---|
| **최소** | Gemini + Claude Pro + 도메인, TTS·게시 도구 무료 | **~$35 (약 5만 원)** | ~$420 (약 59만 원) |
| **권장** | 최소 + ElevenLabs Starter + Gemini 여유분(2배) + 예비비 $10 | **~$65 (약 9만 원)** | ~$780 (약 109만 원) |
| 확장 (반응 확인 후) | 권장에서 TTS 를 ElevenLabs Creator($22)로 + Buffer 유료(채널당 월 ~$6 × 3) | ~$100 (약 14만 원) | — |

- Claude Pro($20)를 이미 개발용으로 결제 중이면 **추가 지출은 최소 월 ~$15, 권장 월 ~$45**.
- 일회성: 도메인 첫 해 ~$10.5, 상표 출원(선택, 브랜드 확정·수익화 직전) — 특허청 수수료표로 류별 비용 확인.

## 4. 비용 절감·리스크 대응
- **Gemini 모델 교체 (첫 PC 점검 때)**: 2.5 계열 일부가 2026-10 종료 예정. `python -m pipeline.llm models` 로 사용 가능 모델 확인 후 `config/models.yaml` 을 Gemini 3.x 로 교체 — 3.x 는 검색 연동 월 5,000회 무료 후 1,000회당 $14 (2.x 는 $35). 사실 수집·주제 조사처럼 검색을 쓰는 단계가 이득.
- 블로그·대본 생성은 Flash 로 내리고 사실 수집만 Pro 유지 → Gemini 비용 약 절반 (품질은 샘플로 확인).
- 배치 API(50% 할인)는 실시간성이 필요 없는 주간 주제 조사에 적용 가능.
- 월 비용 상한: Google AI Studio 에서 결제 한도·예산 알림 설정 (예: 월 $30 알림).

## 5. 정보 제공 기간 로드맵 (12개월 가정)
| 기간 | 목표 | 판단 기준 |
|---|---|---|
| 1~2개월 | PC 설치·첫 실행, 샘플 품질 확인, 브랜드·도메인·계정 개설, 블로그·추적기 배포, 비공개 테스트 1주 → 게시 시작 | 파이프라인이 사람 개입 주 2~3시간 안에서 돌아가는가 |
| 3~4개월 | 주 5편 꾸준히 게시, 채널별 완주율·공유·팔로우 비교 (기획서 10장 KPI) | 집중 채널 선정, 검수 일치율로 신뢰 단계 2로 이동 |
| 5~8개월 | 블로그 글 누적(AI·검색 유입 자산), Search Console·Bing 색인 확인, AI 답변 인용 여부 관찰 | 블로그 월 방문·AI 유입 추이 상승 |
| 9~10개월 | 인맥 병원 1~2곳 **무상 파일럿** (스폰서 트랙 + 유입 리포트) | 파일럿 리포트 수치 확보 |
| 11~12개월 | 법률 자문 → 계약서·요금제 확정 → 유료 영업 시작 | 첫 정액 계약 |

- 무상 파일럿도 광고 표시·병원 확인·검수는 유료와 동일하게 적용 (돈을 받지 않아도 광고는 광고).
- 12개월 누적 권장 예산 약 109만 원 = 첫 병원 1곳 몇 달치 정액 계약으로 회수 가능한 규모가 목표선.
