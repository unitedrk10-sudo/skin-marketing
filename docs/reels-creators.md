# 리믹스 원본 크리에이터 후보 (한국어 시술·피부 영상)

작성 2026-11-05 · 상태: 1차 조사, 운영자 확인 전 · 용도: 리믹스 번역 릴스 원본 찾기 (`docs/shortform-ops-handoff.md` "리믹스 번역 릴스")

`docs/creator-outreach.md`(영어권 유튜브 크리에이터, 자료 제공 연락용)와는 다른 목록이다. 여기 목록은 **한국어로 시술·피부 경험을 올리는 인스타그램 계정**이고, 리믹스 원본을 찾는 데만 쓴다.

## 조사 방법과 한계

- 웹 검색(기사·마케팅 자료·유튜브)으로 찾았다. **인스타그램 릴스는 검색 엔진에 거의 색인되지 않아** 계정·팔로워 수를 웹에서 확인하기 어렵다.
- 인스타그램 계정 주소가 확인된 곳만 주소를 적고, 나머지는 이름만 적었다. **계정 주소를 추측해 적지 않는다.**
- 팔로워 수는 출처에 나온 값이고 지금 값과 다를 수 있다.
- 확정 방법:
  - 지금: 운영자가 앱에서 확인
  - API 연결 뒤: Business Discovery 로 팔로워 수와 최근 게시물을 받는다

**주의 — 제조사 협찬이 많다:** 리쥬란 제조사가 인플루언서 약 50명을 써서 '자연스러운 피부 개선' 콘텐츠를 냈다는 보도가 있다 (검색 요약에서 확인, 어느 기사인지는 미확인 — 후보: [한국경제](https://www.hankyung.com/article/2025030283171), [스마트투데이](https://www.smarttoday.co.kr/ko-kr/articles/56927), [메디칼타임즈](https://medicaltimes.com/Main/News/NewsView.html?ID=1142144)). 유명 크리에이터의 리쥬란 영상은 제조사 협찬일 가능성이 높으므로 협찬 표시·신호가 있으면 병원 협찬과 같이 뺀다.

**현실적인 기대:** 상위 메이크업 크리에이터는 시술 릴스가 드물다. 시술 리믹스는 디렉터파이 같은 **피부 관리형 크리에이터**와 중간 규모 개인 계정에서 주로 나올 것이다. 상위 크리에이터는 **화장품(올리브영) 주제**에서 원본이 훨씬 많다.

### 시술 리뷰 상위 크리에이터 조사 (2026-11-05 3차)

- 웹에서 찾히는 시술 리뷰 상위 채널은 대부분 **피부과 전문의 채널**(의료인 광고 → 제외)이거나 **연예인**(제외)이다.
- 일반인 시술 후기 채널은 유튜브 영상은 보이지만 채널 이름·규모가 검색 요약에 나오지 않는다. 운영자가 채널을 열어 이름을 확인하고, 같은 사람의 인스타그램 릴스가 있는지 본다:
  - [피부과에 N천만 원 쓴 사람의 시술 티어리스트](https://www.youtube.com/watch?v=adNrrYKwsEM)
  - [광고 없는 100% 솔직후기 (미백주사, 슈링크, 윤곽주사 등)](https://www.youtube.com/watch?v=1LkjXuxfrio)
  - [제 얼굴 싹 갈아 엎어준 시술들 다 공개합니다](https://www.youtube.com/watch?v=D6jzSVcnVFE)
- 결론: 시술 리뷰만 하는 "유명 일반인 크리에이터" 층은 얇다. 시술 리믹스는 중간 규모 개인 계정에서 주로 나온다.
