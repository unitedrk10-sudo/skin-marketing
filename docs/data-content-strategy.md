# 공공 데이터 콘텐츠 전략 (Skinbound Data)

작성 2026-11-02 · 상태: 승인, 1번 글 진행 중

## 1. 왜 블로그와 나누는가

| | 기존 블로그 | Skinbound Data |
|---|---|---|
| 독자의 질문 | "나는 어떻게 해야 하나" | "실제 숫자는 어떤가" |
| 하는 일 | 시술과 여행 실무 안내 | 공개 통계를 정리해 인용 가능한 근거 제공 |
| 경쟁 상대 | 병원 사이트, 시술 정보 사이트 | 정리된 영어 자료가 드묾 (11/2 조사에서 정식 비교는 안 함) |
| 기대 효과 | 검색 유입 | 외부 링크, 기자·블로거·AI의 인용 |
| 주기 | 월·수·금 | 월 2편, 데이터 갱신 때 수정 |

11/2 인용 점검에서 인용된 출처는 대부분 병원과 시술 정보 사이트였다. 이들은 자기 시술을 소개하는 입장이라, 중립적인 집계 자료는 우리가 내세우기 좋은 차별점이다. 효과는 아직 검증되지 않았다.

## 2. 구조

- **주소:** `/data/`를 첫 화면으로 하고, 글은 `/data/notes/<주제>/`에 둔다.
- **주간 주제 쿼터와 별개:** 블로그 주 3편에 포함하지 않는다.
- **글 구조:** 핵심 숫자 한 문장 → 그래프 1~2개 → 읽는 법 → 한계 → 원자료와 CSV.
- **AI가 인용하기 쉬운 형식:** 첫 문장에 기준일, 숫자, 출처를 함께 쓴다. 표는 HTML로 제공한다.
- **블로그와 연결:** 관련 블로그 글에서 수치 근거로 링크한다. 블로그 글의 신뢰 근거가 되고, 내부 링크로 색인에도 도움이 될 수 있다.

## 3. 만드는 방식

기존 글처럼 AI가 사실을 수집하지 않는다. **숫자는 코드가 계산하고, AI는 설명만 쓴다.**

1. 코드가 데이터 세트에서 표와 숫자 목록을 만든다.
2. Claude가 그 목록만 사용해 영어 설명을 쓴다.
3. 코드가 본문의 모든 숫자를 목록과 대조한다. 목록에 없는 숫자가 있으면 차단한다.
4. Gemini가 해석이 과하지 않은지 검수한다.
5. 운영자가 승인한다. **신뢰 단계 자동 승인을 적용하지 않는다.**
6. 데이터를 갱신하면 숫자가 바뀐 글을 수정 후보로 알린다.

## 4. 지키는 선

- 병원명, 병원별 수치, 순위, "어디가 좋다"는 해석을 넣지 않는다.
- 많다는 것을 좋다는 뜻으로 쓰지 않는다.
- 진료과목 기관 수를 전문의 수처럼 쓰지 않는다.
- 공공누리 출처 표시를 코드가 항상 붙인다.
- 스폰서 글을 섞지 않고, 숫자를 광고주에게 유리하게 고르지 않는다.
- 언론 보도 수치를 원자료처럼 쓰지 않는다.

## 5. 첫 콘텐츠 후보

아래 숫자는 2026-11-02 심평원 데이터로 계산했다.

| 순서 | 제목 초안 | 핵심 내용 | 공유될 이유 | 준비 상태 |
|---|---|---|---|---|
| 1 | Where Korea's dermatology institutions actually are | 서울 28.1%, 경기 23.0%, 강남구만 1,230곳으로 전국의 6.9% | 지도로 한눈에 보이는 놀라움 | 바로 가능 |
| 2 | "Dermatology department" vs "dermatology" on the sign | 진료과목 기관 17,871곳 중 이름에 피부과가 들어간 곳 1,559곳(8.7%) | 여행 전에 친구에게 알려 줄 실용 정보 | **의료법의 명칭 규정 확인 후** |
| 3 | How many dermatology institutions are near popular places in Seoul | 700m 안 기관 수: 강남·신사 303곳, 명동 96곳, 경복궁 6곳 | 여행 계획과 바로 연결 | 관광지 수치를 같은 날짜로 갱신 후 |
| 4 | Foreign patients at Korean dermatology departments | 연도별 환자 수와 국적 추이 | 언론과 업계의 인용 수요 | KHIDI 원문과 이용 조건 확인 후 |
| 5 | 분기별 변화 | 지역별 증감 | 정기 인용 | 두 번째 갱신(2027년 1월) 이후 |

**1번부터 시작하고, 사람들이 가장 많이 공유할 만한 2번을 그다음으로 낸다.** 2번은 진짜 전문의 수를 잰 값이 아니므로 "이름만 보고 판단하지 말고 의사의 자격을 확인하라"는 안내로 쓴다.

## 6. 알리는 방법

사이트에 올리는 것만으로는 부족하다. 글마다 아래를 함께 한다.

- 그래프 한 장을 Threads와 X에 올린다. 숫자 하나를 이미지로 보여 주고, 링크는 답글에 둔다.
- 한국 의료관광을 다루는 영어 기자, 여행 블로거, 뉴스레터에 자료 제공 메일을 보낸다. 월 3~5곳부터 시작한다. 발송은 운영자가 직접 한다.
- 관련 Reddit 질문에는 운영진 답변을 받은 커뮤니티에서만 언급한다. Reddit 세션과 조율한다.

## 7. 성과 판단

| 지표 | 2027년 1월 판단 신호 |
|---|---|
| 외부 사이트 링크 (Search Console, Bing) | 1곳 이상 |
| 데이터 페이지를 읽는 AI 봇 | 글 읽기 발생 |
| Gemini·ChatGPT·Perplexity 인용 | 데이터 질문에서 1회 이상 |
| 그래프 게시물 공유 | 일반 SNS 글 평균보다 높음 |

인용 점검 질문에 "How many dermatology clinics are in Gangnam?" 같은 데이터 질문을 추가한다. 기존 질문과 나눠 집계해야 추이가 끊기지 않는다.

## 8. 작업 순서

1. 데이터 노트 틀과 숫자 대조 검사 개발
2. 그래프 생성 (지도 또는 막대)
3. 1번 글 작성과 운영자 승인
4. 의료법 명칭 규정 확인 후 2번 글
5. 관광지 수치 갱신 후 3번 글
6. KHIDI 원문 확보 후 4번 글
