## 3. 개편 내용 (W50 적용 목록)

### A. 신뢰 장치 — `pipeline/site.py` (LLM 호출 없음)
- **A1. 정책 페이지 `/policies/`** — "Editorial & advertising policy", 최종 검토일 표시.
  - 단락: 글 만드는 방식 · 병원 목록(공공데이터·전부·거리순, 돈으로 추가·삭제·순서 변경 불가) · 광고 카드(Ad, 정액, 해외 방문자만) · 스폰서·파트너 글 · 제휴 링크 · 예약 도움 서비스 원칙(5번 결정) · 현재 개수(코드가 셈, 지금 About의 `funding_html`).
- **A2. 문맥 링크** — 스폰서 배지, 광고 카드, 병원 목록 머리, 제휴 표시, 대기 명단 양식 → 정책 페이지의 해당 단락(`#clinic-lists` 등). 꼬리말·sitemap·llms.txt에도 넣는다.
- **A3. About 정리** — 광고·제휴·스폰서·수익 4단락을 요약 3줄 + 정책 링크로 줄인다. "Who runs"와 정정 기록은 About에 남긴다.

### B. 콘텐츠 — "Before you book" 축
- **B1. 첫 주제(순서 제안):**
  1. 간판·전문의 구별 (`checking-a-doctor` + 메모 1번: 의료법 시행규칙의 명칭·진료과목 표시, 조문 번호는 작성 전에 법령 API로 확인)
  2. 첫 상담: 상담실장과 의사 (`consultation-for-foreigners` + 메모 2번)
  3. 누가 시술하나 (새 주제, 메모 3번: 대리 시술 문제·의사 지정 추가금·확인 방법 — 단속 사례는 확인된 보도만)
  4. 견적 읽기 (`reading-a-quote` + 메모 4번: 단위·"무료 추가"·서면 견적, 등록 병원의 서면 안내 의무 유치법 제8조 2항)
  - 다음 후보: 등록 병원 확인 (`check-registered-clinic`) · 부가세 환급 종료 (`vat-refund-ended-2026`) · 귀국 후 문제가 생기면 (`complications-after-returning`)
- **B2. 법령 원문을 출처로** ✅: seed 주제의 `sources:`에 law.go.kr 조문 한글 주소(`/법령/<법령명>/제N조`)를 적으면 국가법령정보 API 본문이 출처 페이지가 된다(`web.law_page`). law.go.kr 화면은 스크립트로 그려져 수집기가 본문을 못 읽기 때문이다. 원문 인용 대조와 02b 재검증도 같은 길로 읽는다. 전에는 seed의 `sources:`가 초안에 쓰이지 않았는데 이제 출처 맨 앞에 들어간다. `config/laws.yaml`에 의료법 시행규칙 제40~42조와 의료법 제24조의2를 추가했다.
- **B3. 출처 원칙:** 경쟁 사이트·병원 블로그는 출처로 쓰지 않는다(메모 그대로). 법령·정부·언론만 쓴다. 병원 이름은 쓰지 않는다.
- **B4. 게시 칸** ✅: 화요일 칸 추가(주 4편, `site.yaml` `tue: before_you_book`, `channels.yaml` `topic_quota.before_you_book: [how_to]`). 목요일 후보는 8개(유형마다 2개). 월요일 시술 설명은 그대로. 화요일 칸은 `starts: tue 2026-12-08`부터라 그 전 화요일(12/1)은 빈 날로 알리지 않는다.
- **B5. 주제 목록 바닥** ✅ (11/27 첫 PR에 포함): 시술×여행 seed가 1개, 화장품 seed가 2개만 남았다(11/26). 지금 코드는 seed가 **전부** 떨어져야 Gemini 조사로 넘어가서, 그 전까지 빈 칸은 다른 유형 주제로 채워진다. 모자란 유형만 Gemini 조사로 보충하게 고친다. → 주제 은행(`content/topics/bank/`): 매월 1일 크론 `skin-topic-bank`가 유형마다 안 쓴 주제 10개가 되게 채우고, 주간 선정 직전에도 유형마다 2개가 안 되면 그 유형만 바로 보충한다. 요일마다 후보 2개.

## 6. 하지 않는 것 (재확인)
- 순위·"best"·최상급·후기 요약·전후 사진·할인·병원별 가격 등급 — 경쟁 사이트에 있어도 하지 않는다
- 경쟁 사이트·병원 블로그를 출처로 쓰기
- 게시된 글 본문 수정, 주소 변경
- 등록 전 상담·예약 연결, 등록된 것처럼 읽히는 문구
